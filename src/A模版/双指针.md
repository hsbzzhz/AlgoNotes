### 左右指针
#### 有序数组的两数之和（左右指针）
- 循环条件为 left < right 区间
```java
public int[] twoSum(int[] nums, int target) {
    int left = 0;
    int right = nums.length - 1;
    while (left < right) { // 核心条件，避免指针重叠
        int sum = nums[left] + nums[right];
        if (sum == target) {
            return new int[]{left + 1, right + 1}; // 题目常要求下标从1开始
        } else if (sum < target) {
            left++;
        } else {
            right--;
        }
    }
    return new int[0];
}
```
### 快慢指针
#### 有序数组去重（前后指针）
- 题干：有序数组中出现重复元素，需要原地去重，返回去重后的数组长度
- 用到快慢指针，初始位置快指针比慢指针位置+1
- 在循环中让快指针自动走，碰到fast==slow情况，slow就不动，让fast继续走；遇到fast!=slow情况，slow+1 = fast
- 原地修改重复元素的值，slow记录有效位置，slow+1为最终长度
```java
public int removeDuplicates(int[] nums) {
    if (nums == null || nums.length == 0) return 0;
    int slow = 0;
    for (int fast = 1; fast < nums.length; fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    return slow + 1;
}
```
#### 三数之和
- 题干：求一个数组中三数之和加起来为0的组合
- 需要先排序，左右指针
- 重点是去重，去重逻辑在sum==0之后，分别判断left、right去重
```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    if (nums == null || nums.length < 3) return res;
    Arrays.sort(nums); // 排序是前提
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] > 0) break; // 剪枝，正数之和不可能为0
        if (i > 0 && nums[i] == nums[i-1]) continue; // 去重
        int left = i + 1;
        int right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // 去重（核心坑点）
                while (left < right && nums[left] == nums[left+1]) left++;
                while (left < right && nums[right] == nums[right-1]) right--;
                left++;
                right--;
            } else if (sum < 0) {
                left++;
            } else {
                right--;
            }
        }
    }
    return res;
}
```

## 例题：求连续的0
非固定长度滑动窗口
```java
    public static int longestOnes(int[] nums, int k) {
        /* 逆向思维，要找到多少个连续的1，就要看窗口里最多有几个0
         *
         * 如果题目是：求连续target（1或0）的个数
         */
        int left =0, right =0, zeron = 0, res =0;
        while (right < nums.length) {
            if (nums[right] == 0) {
                zeron++;
            }
            while (zeron > k) {
                if(nums[left] == 0) {
                    zeron--;
                }
                left++;
            }
            res = Math.max(res, right-left+1);
            right++;
        }
        return res;
    }

```
